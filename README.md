# QuestTick

原生 Android 米游社签到工具，支持米游社游戏签到与云游戏免费时长领取。

当前版本：**1.0.0**。

技术栈：**Kotlin + Jetpack Compose + Material 3 + Hilt + Room + OkHttp + WorkManager**。

> 本项目仅供学习和交流使用。请在遵守相关服务条款与法律法规的前提下使用；
> 若不同意，请停止使用。

## 功能特性

- **多账号管理**：支持添加、编辑、删除及启用/停用多个账号。
- **扫码登录**：支持米游社、云原神、云崩铁扫码登录，减少手动复制凭证。
- **凭证刷新**：支持 Cookie / Token 失效后的自动刷新与手动刷新。
- **游戏选择**：可按账号选择需要执行的米游社游戏与云游戏任务。
- **一键执行**：首页可执行全部已启用账号的签到任务；实验功能支持多账号并行处理。
- **定时签到**：基于 WorkManager 按设定时间执行，并在开机、时间或时区变化后重新调度。
- **结果通知**：支持系统通知展示签到结果。
- **邮件推送**：支持 SMTP 邮件推送签到结果摘要。
- **签到日历与记录**：展示每日状态、连续签到天数及奖励信息；记录仅保留最近 30 天。
- **运行日志**：统一记录各功能的原始错误类型、消息和原因链，支持筛选、搜索与展开详情；日志仅保留最近 30 天。
- **日志导出**：支持导出 TXT / JSON / ZIP 诊断文件。
- **奖励图片缓存**：只在展开对应记录时加载，相同图片复用本地缓存。
- **缓存管理**：按类别查看和清理缓存，大小为 0 时禁止清理。
- **版本与 ACT_ID 管理**：米游社和云游戏版本按需获取；ACT_ID 仅在接口提示失效时自动刷新。
- **本地加密**：Cookie、Token、SMTP 密码等敏感信息使用本地加密存储。
- **安全检测**：Root 检测与阻断始终优先于签到任务。
- **外观设置**：支持浅色、深色、跟随系统、动态配色及 OLED/AMOLED 优化。

## 快速使用

1. 打开应用，进入“账号”页。
2. 点击添加账号。
3. 填写账号名称。
4. 填写米游社 Cookie，或使用“扫码登录”。
5. 如需云游戏免费时长领取，填写云游戏 Token，或使用云游戏“扫码登录”。
6. 在“游戏选择”中勾选需要执行的项目。
7. 保存账号。
8. 回到首页，点击“开始签到”。
9. 如需自动执行，在“设置 → 定时任务”中开启定时签到，填写时间后点击保存。

## 凭证与登录说明

### 米游社 Cookie

米游社签到需要有效 Cookie。推荐使用应用内扫码登录；
扫码登录成功并选择保持登录后，应用会保存刷新凭证，用于后续自动刷新 Cookie。

### 云游戏 Token

云原神、云崩铁免费时长领取需要对应云游戏 Token。推荐使用应用内云游戏扫码登录；
扫码登录成功并选择保持登录后，应用会保存续期所需凭证。

### 敏感信息安全

- Cookie、Token、SMTP 密码只保存在本机。
- 敏感字段会通过 Android Keystore 相关机制进行本地加密保存。
- 日志与导出内容会自动脱敏，避免直接泄露完整 Cookie / Token。
- 请勿将包含个人凭证的截图、日志或导出文件公开发布。

## 设置说明

### 定时任务

开启后，应用会在设定时间附近由系统调度执行签到。Android 系统可能会因为省电策略、
后台限制、厂商管控等原因延迟或阻止后台任务。

开启或关闭开关只改变定时签到状态；时间需要手动填写并点击时间区域右侧的保存按钮后才会写入。

如需提高成功率，建议：

- 允许应用通知权限；
- 将应用加入电池优化白名单；
- 在厂商系统中允许自启动 / 后台运行；
- 避免频繁清理后台或强行停止应用。

### 邮件推送

邮件推送使用 SMTP。常见邮箱通常需要使用“授权码”而不是登录密码。

请确认：

- SMTP 服务器地址正确；
- SMTP 端口正确；
- 发件邮箱和授权码正确；
- 收件邮箱填写正确，多个邮箱可使用英文逗号分隔。

### 版本设置

应用支持配置米游社与云游戏版本号。自动获取仅在实际签到过程中执行，同一版本源最多每 3 天获取一次。
设置页手动获取只会填入输入框，点击保存后才会覆盖本地记录。

### ACT_ID 自动刷新

开启后不会定期请求 ACT_ID。只有对应游戏签到接口明确提示 ACT_ID 失效时，应用才会刷新并重试。

### 调试日志

调试日志用于排查接口请求、任务执行、凭证刷新等问题。开启后日志信息会更详细，
错误日志会保留异常类型、原始消息和原因链，并在保存和导出前统一脱敏。

### 缓存管理

“设置 → 缓存管理”可分别查看并清理图片、更新安装包和日志导出文件等缓存。
缓存清理不会删除账号、Cookie、设置、签到记录、运行日志、ACT_ID 或设备 ID。

## 构建

### 环境要求

- JDK 21
- Android SDK
- Gradle Wrapper

### Release 构建

```bash
./gradlew :app:assembleRelease
```

Release 构建需要签名配置。

## 签名配置

Release 构建可使用环境变量或本地 `keystore.properties`。

示例：

```properties
storeFile=release.keystore
storePassword=your_store_password
keyAlias=your_key_alias
keyPassword=your_key_password
```

请注意：

- 不要提交签名文件；
- 不要提交密码、Token、Cookie 等敏感信息；
- 建议使用本地文件或 CI Secret 管理签名信息。

## 日志与问题排查

如果签到失败，可以优先检查：

1. 账号凭证是否过期；
2. 是否遇到验证码、短信验证或风控；
3. 米游社或云游戏版本号是否失效；
4. ACT_ID 是否已失效且自动刷新未开启；
5. 系统是否限制后台运行；
6. “运行日志”中是否存在明确的异常类型、HTTP 状态码、retcode 或原始错误信息。

导出日志时，应用会尽量脱敏，但仍建议在公开反馈前自行检查内容。
