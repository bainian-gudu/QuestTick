# ================================================================
# MYS_Signin_Android Baseline Profile
# ================================================================
#
# 此文件由人工 + Macrobenchmark 共同维护。
# AOT 预编译列表（HSPL）会让 ART 在安装时就把这些方法编译成机器码，
# 显著降低首次启动 / 冷启动 / 关键交互的 jank 和 CPU 占用。
#
# 格式说明：
#   HSPL<package/class/method>-><signature>     — Hot-Specific Method（精确）
#   HSPL<package/class>*->**(**)**              — Hot-Static：包/类下所有方法
#   L<class>;                                     — 类初始化器
#
# ★ 与源码对应：
#   - ui/ 包：所有 Compose 屏幕和 ViewModel（启动后立即渲染）
#   - data/ 包：SecureStore / Repository（启动时预热，签到后立即读取）
#   - sign/ 包：SignInRunner + 签到引擎（定时任务首次执行）
#   - mail/ 包：Mailer.send（签到完成通知，热点路径）
#   - notify/ 包：Notifier.showResult（本地通知，热点路径）
#   - work/ 包：SignInWorker（定时任务入口）
#   - net/ 包：Http.client / execute（每次网络请求都走）
#
# ★ 本次更新（基于 13 处修复）：
#   1. 加入 mail/Mailer.kt（签到完成时邮件推送，热点）
#   2. 加入 notify/Notifier.kt（签到完成时本地通知，热点）
#   3. 显式列出 SignInRunner 关键方法（runAll / processAccount / notifyAccountChanged）
#   4. 显式列出 SecureStore 关键写入方法（saveLogs / addRunRecord / saveActIdCache）
#   5. 显式列出 LogExporter.buildText / suggestFileName（用户导出日志）
#   6. 显式列出 CookieRefresher.refresh（Cookie 过期时调用，热点）
# ================================================================
